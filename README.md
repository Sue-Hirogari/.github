# .github

Sue-Hirogari の組織の、既定のファイルを置くリポジトリ。

ここに置いた Issue と PR のテンプレートは、自前のテンプレートを持たない、組織のすべてのリポジトリに効く。GitHub の仕様で、このリポジトリは公開になっている。

| ファイル | 内容 |
|---------|------|
| `.github/ISSUE_TEMPLATE/issue.md` | Issue のテンプレート |
| `.github/PULL_REQUEST_TEMPLATE.md` | PR のテンプレート |

リポジトリが自前のテンプレートを置くと、そのリポジトリでは、自前のものが使われる。
